### Hi, I'm Rodrigo 👋

I'm a fourth-year Programming Engineering + Game Design & Production student at U-tad.
I like understanding how things work under the hood: why a river ends up carving a valley, how an
engine decides what to draw every frame, or what an AI agent needs so it doesn't lose track halfway
through a task. Most of what I build comes from that curiosity.

These days I split my time between three things:

- **Graphics programming** — procedural terrain in C++20 and OpenGL 4.6 where the landscape isn't
  painted, it's simulated: stream-power erosion, D8 hydrology and baked lighting.
- **Games in Unreal Engine 5** — multiplayer, geometry generated from code, and a VR take on
  Escher's impossible staircase.
- **Applied AI** — a desktop cockpit that orchestrates LLM agents with its own memory, and a grand
  strategy game where a language model acts as the game master.
